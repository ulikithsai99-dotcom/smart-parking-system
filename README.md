# Smart Parking System

A web-based Smart Parking System designed to optimize parking space utilization through real-time monitoring, automated slot allocation, reservation management, and parking analytics.

## Features

- Real-time parking slot monitoring
- Parking space allocation
- Reservation management
- Database integration using SQLite
- User-friendly web interface
- Parking data tracking and analytics

## Technologies Used

- Node.js
- Express.js
- SQLite
- HTML
- CSS
- JavaScript

## Project Structure

```
smart-parking-system/

```

