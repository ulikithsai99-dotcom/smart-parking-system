# Smart Parking System

A web-based smart parking management platform with real-time slot monitoring, reservation management, and an admin dashboard.

## How to run

The app runs via `node server.js` on port 5000.

- User portal: `/user`
- Admin login: `/admin`
- Parking map: `/map`

## Architecture

- **Backend:** Node.js + Express
- **Database:** SQLite (`database.db`) — 200 parking slots across zones A–D
- **Frontend:** Static HTML/CSS in `views/`
